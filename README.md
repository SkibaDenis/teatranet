# ТЕАТРА НЕТ — Культурная платформа и карта независимых театров России

Веб-сайт и инфраструктура документального видеопроекта **«Театра нет»** (обзоры коммерческих и независимых театров России с регулярностью раз в месяц, интерактивная карта страны, видеоплеер YouTube / VK Видео и платформа для связи театров, меценатов и зрителей).

---

## Быстрый старт локально

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск сервера разработки
npm run dev
```
После запуска откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Как устроена архитектура (где что менять)

Проект специально спроектирован так, чтобы вы могли легко менять дизайн, логотип, шрифты и добавлять новые видеовыпуски без переписывания кода компонентов:

### 1. Смена логотипа, цветов, текстов о ведущем и ссылок
Откройте файл [`src/config/brand.config.ts`](./src/config/brand.config.ts):
- **Логотип**: По умолчанию включён режим `mode: "typographic"`. Когда появится готовый графический логотип, положите файл в `public/logo.svg` и переключите `mode: "image"`.
- **Цвета и атмосфера**: Акцентные цвета софита (`spotlightAmber`) и занавеса (`curtainCrimson`) настраиваются в `src/config/brand.config.ts` и `src/app/globals.css`.
- **Шрифты**: Подключены в [`src/app/layout.tsx`](./src/app/layout.tsx) (`Cormorant Garamond` для заголовков + `Manrope` для интерфейса). Их можно заменить на любые другие шрифты из `next/font/google` или локальные `.woff2` файлы в пару строк.

### 2. Как выложить смонтированный 1-й выпуск или добавить новый театр на карту
Откройте файл [`src/data/theatres.ts`](./src/data/theatres.ts):
1. Найдите первый объект (`id: "pilot-episode-1"`) или добавьте новый элемент в массив `THEATRES_DATA`.
2. Укажите город через поле `cityKey` (например: `'novosibirsk'`, `'moscow'`, `'spb'`, `'ekaterinburg'`, `'kazan'`, `'perm'`, `'voronezh'`, `'rostov'`, `'krasnoyarsk'`, `'vladivostok'` и др. — полный список из 30+ городов в [`src/data/cities.ts`](./src/data/cities.ts)). Точка сама встанет на нужное место на карте России!
3. В блоке `video` укажите:
   - `status: "released"` (выпуск вышел), `"editing"` (на монтаже) или `"upcoming"` (в планах)
   - `youtubeId` — ID ролика или ссылка на YouTube
   - `vkEmbedUrl` — ссылка на плеер VK Видео (на случай замедления YouTube у зрителей в РФ)
4. В блоке `needs` укажите актуальные запросы театра для спонсоров и меценатов (свет, звук, аренда, партнёр премьеры).

### 3. Уведомления о заявках от театров и спонсоров в Telegram
Все заявки из раздела «Связываем независимые театры, бизнес и людей культуры» обрабатываются в [`src/app/api/applications/route.ts`](./src/app/api/applications/route.ts):
- Локально и на VPS они автоматически сохраняются в файл `submissions.json`.
- Чтобы заявки мгновенно приходили вам в Telegram, создайте файл `.env.local` в корне проекта и добавьте:
  ```env
  TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
  TELEGRAM_CHAT_ID=ваш_id_чата_или_канала
  ```
